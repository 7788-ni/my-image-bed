使用说明

一、获取 GitHub Personal Access Token

  1. 登录 GitHub，进入 Settings > Developer settings > Personal access tokens
  2. 点击 Generate new token (classic)
  3. 勾选 repo 权限（Full control of private repositories）
  4. 生成并复制 Token

二、配置本工具

  1. 展开顶部"设置"面板
  2. 填入你的 GitHub 用户名、仓库名、分支名
  3. 填入上一步复制的 Token
  4. 外链格式保持默认或按需修改
  5. 点击"保存配置"

三、上传与管理文件

  1. 在上传区域点击或拖拽选择文件
  2. 等待上传完成，查看进度和状态
  3. 在图库区域管理你的文件：复制链接、打开原图、删除文件

四、部署到 GitHub Pages（可选）

  1. 将此 HTML 文件保存为 index.html
  2. 上传到仓库根目录
  3. 进入仓库 Settings > Pages，Source 选择 main 分支
  4. 访问 https://你的用户名.github.io/仓库名/ 即可使用

注意事项

  • Token 仅保存在你的浏览器本地，不会上传到任何服务器
  • 建议在手机浏览器中使用"桌面版网站"模式获得最佳体验
  • 单次上传文件大小建议不超过 10MB
